    How it works

    From a description to a verdict in three steps.

    1. 1

      Describe

      You answer 21 questions about the mushroom: its smell, cap, gills, stalk, ring, and where it grows.

    2. 2

      Encode

      Each answer becomes a row of on/off switches (one-hot encoding). Models can only do maths with numbers, not words.

    3. 3

      Predict

      Both models look at the switches and answer edible or poisonous.

    Decision Tree: "20 Questions"

    While training, the tree searched for the single question that best separates poisonous from edible mushrooms, then repeated that inside each group. Its first question is "Does it have no smell?", because smell alone sorts most mushrooms correctly.

    • Easy to read: you can follow every step
    • Very fast: about 7 questions at most

    K-Nearest Neighbors: "Ask the neighbours"

    KNN learns no rules. It remembers every training mushroom and, for a new one, finds the most similar ones by counting how many answers differ. Then it copies their label. Mushrooms of the same species look almost identical, so this works very well.

    • Simple idea, with no rules to learn
    • Slower: it compares against every stored mushroom

    Why smell matters so much

    Almond and anise smells are always edible. Foul, fishy, spicy, pungent, creosote and musty are always poisonous. Only "no smell" is mixed, so that's where the models need more clues.

    How good are the models?

    Both models were trained on 80% of the mushrooms and tested on the other 1,625, which they had never seen.

    Confusion matrices

    Rows are the true answer, columns are the model's answer. Anything outside the diagonal is a mistake. The dangerous mistake is a poisonous mushroom predicted as edible.

    About the project

    This is a beginner machine-learning project. The data is the UCI Mushroom Dataset: 8,124 mushrooms from 23 species of the Agaricus and Lepiota families, each described by 22 features.

    The models were built in Python with scikit-learn in mushroom_classification.ipynb, then exported by export_model.py so this page can run them in your browser.

    Limitations

    • It only knows 23 species. A mushroom outside the dataset can get a confident but wrong answer.
    • It can't use photos. Key clues like smell and spore print colour have to be observed in person.
    • A wrong description gives a wrong prediction.
